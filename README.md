## Descrição primaria do passo a passo para executar o servidor
1. Clonar o repositorio
2. executar npm install
3. criar .env (PORT, DATABASE_URL, TMDB_API_KEY, JWT_SECRET)
4. executar npx prisma generate
5. rodar npm run dev
